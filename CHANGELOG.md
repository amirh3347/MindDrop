## [1.0.0] - 2026-10-27

### Added
- Quick capture sheet with smart parsing: `#tags`, `!`/`!!`/`!!!` priority and
  `today` / `tomorrow` (also `امروز` / `فردا`).
- Inbox, Today, Upcoming and Done views with sections, tag filter and badges.
- Task editor: notes, priority, due date and time, reminder, tags, subtasks, pin.
- Reminder notifications that survive reboots.
- Instant search across titles, notes, subtasks and tags with status, priority and tag
  filters; forgiving Persian/Arabic text matching.
- Swipe to complete or delete, with undo. Long-press menu with pin and duplicate.
- Statistics: open/completed/overdue counts, daily streak, last 7 days chart, top tags.
- Dark (default), light and system themes, pure-black AMOLED mode and 8 accent colors.
- Persian and English UI with right-to-left layout, Persian digits and the Solar Hijri
  (Jalali) calendar; language and theme chosen on first launch.
- Backup: export to a file or share it, import with merge or replace.
- "Share → MindDrop" from any app, and launcher shortcuts for new task and search.
- GitHub Actions pipelines for CI builds and signed releases.
