## چرا MindDrop؟

بیشتر اپ‌های کار می‌خوان برنامه‌ریزی کنی. MindDrop برای اون لحظه‌ی دیگه‌ست: داری راه
می‌ری، آشپزی می‌کنی، یا نیمه‌خوابی و یهو یادت میاد باید یه کاری رو بعداً انجام بدی. اپ رو
باز می‌کنی، یه خط می‌نویسی، Enter می‌زنی. دو ثانیه و تمام. مرتب کردنش بمونه برای بعد.

## امکانات

- ⚡ **ثبت سریع:** یه لمس، یه خط، Enter. با `#برچسب`، با `!` یا `!!` یا `!!!` اولویت،
  و با «امروز» یا «فردا» تاریخ بده. همه موقع تایپ تشخیص داده می‌شن. با «ذخیره و بعدی»
  می‌تونی چندتا فکر رو پشت‌سرهم ثبت کنی.
- 🗂️ **نماهای هوشمند:** **همه** (سنجاق‌شده، عقب‌افتاده، امروز، پیش رو، بدون تاریخ)،
  **امروز**، **پیش رو** (به تفکیک روز) و **انجام‌شده**. با یه لمس بر اساس برچسب فیلتر کن.
- ✍️ **کارهای کامل:** یادداشت، اولویت، تاریخ و ساعت، یادآور، برچسب، زیرکار با نمایش
  پیشرفت، سنجاق. همه‌چیز خودکار ذخیره می‌شه.
- 🔔 **یادآور:** اعلان سر ساعت دقیق که بعد از ری‌استارت گوشی هم سر جاشه.
- 🔍 **جستجوی آنی:** توی عنوان، یادداشت، زیرکارها و برچسب‌ها، با فیلتر وضعیت، اولویت
  و برچسب. ی و ک عربی، نیم‌فاصله و اعداد فارسی رو درست می‌فهمه.
- 👆 **حرکات لمسی:** به چپ بکش یعنی انجام شد، به راست بکش یعنی حذف. همیشه با دکمه‌ی
  «برگردون». با نگه داشتن انگشت روی هر کار، گزینه‌های بیشتر میاد.
- 🎨 **تم:** پیش‌فرض تیره، با گزینه‌ی روشن یا هماهنگ با سیستم. حالت مشکی کامل
  (AMOLED) و ۸ رنگ اصلی.
- 🌐 **فارسی و انگلیسی:** چیدمان کامل راست‌به‌چپ، اعداد فارسی و تقویم شمسی (یا میلادی،
  به انتخاب خودت). زبان و تم موقع اولین اجرا پرسیده می‌شه.
- 💾 **پشتیبان‌گیری و انتقال به گوشی جدید:** خروجی کامل در یک فایل JSON که می‌تونی
  ذخیره‌اش کنی یا به تلگرام، درایو یا ایمیل بفرستی، و روی گوشی دیگه وارد کنی (ادغام یا
  جایگزینی).
- 📤 **اشتراک‌گذاری به MindDrop:** هر متن یا لینکی رو از هر اپی Share کنی، تبدیل به کار
  می‌شه.
- 🚀 **میانبر روی آیکون:** انگشتت رو روی آیکون اپ نگه دار تا «کار جدید» و «جستجو» بیاد.
- 📊 **آمار:** تعداد کارهای باز، انجام‌شده و عقب‌افتاده، روزهای پیاپی 🔥، نمودار ۷ روز
  اخیر و برچسب‌های پرکاربرد.
- 🔒 **حریم خصوصی:** بدون اکانت، بدون تبلیغ، بدون ردیابی و حتی بدون دسترسی به اینترنت.

## نصب

۱. صفحه‌ی [آخرین نسخه](https://github.com/OWNER/MindDrop/releases/latest) رو روی گوشی باز کن.<br>
۲. فایل `MindDrop-vX.Y.Z.apk` رو دانلود کن و بازش کن.<br>
۳. اگه اندروید پرسید، اجازه‌ی نصب از مرورگر یا فایل‌منیجر رو بده.

حداقل **اندروید ۷**. نسخه‌های جدید روی نسخه‌ی قبلی نصب می‌شن و اطلاعاتت حفظ می‌شه.

## انتقال به گوشی جدید

۱. **گوشی قدیمی:** تنظیمات ← پشتیبان‌گیری و داده‌ها ← «خروجی گرفتن در فایل» (یا «ارسال
فایل پشتیبان» برای فرستادن به تلگرام یا درایو).<br>
۲. **گوشی جدید:** MindDrop رو نصب کن، بعد تنظیمات ← پشتیبان‌گیری و داده‌ها ← «وارد کردن از
فایل».<br>
۳. «ادغام» کارهای فعلی رو نگه می‌داره و بقیه رو اضافه می‌کنه. «جایگزینی» همه‌چیز رو از روی
فایل پشتیبان از نو می‌سازه.

## بیلد گرفتن

لازم نیست هیچ چیزی روی سیستمت نصب کنی. **GitHub Actions خودش APK رو می‌سازه:**

- هر push به `main`: یه نسخه‌ی آزمایشی می‌سازه (تب Actions ← اجرای مربوطه ← Artifacts).
- هر تگ مثل `v1.0.0`: یه APK امضاشده می‌سازه و توی صفحه‌ی Releases منتشر می‌کنه.

راهنمای قدم‌به‌قدم، از جمله ساخت کلید امضا که فقط یک بار لازمه، توی
[docs/BUILDING.md](docs/BUILDING.md) هست.

```bash
git tag v1.0.0
git push origin v1.0.0
```
